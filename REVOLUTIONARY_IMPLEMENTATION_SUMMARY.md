## 🎓 Interview-Ready Explanations

### Design Philosophy
**Q: Why "living organism" metaphor?**
**A:** Climate change is a living, evolving challenge. Our interface mirrors this by breathing, pulsing, and growing—creating emotional connection and making abstract carbon data feel tangible and personal.

### Technical Implementation
**Q: How did you optimize performance?**
**A:** Hardware-accelerated CSS transforms, Canvas API for particles, requestAnimationFrame for smooth 60 FPS, particle pooling to avoid garbage collection, and Intersection Observer for lazy loading.

### User Experience
**Q: Won't animations be distracting?**
**A:** All animations serve a purpose—providing feedback, creating delight, or guiding attention. Plus, we have full `prefers-reduced-motion` support for users who need it.

### Accessibility
**Q: How is this accessible?**
**A:** Full WCAG 2.1 AA compliance with reduced-motion support, high-contrast mode, semantic HTML, keyboard navigation, and screen reader descriptions. Animations enhance but don't block core functionality.
